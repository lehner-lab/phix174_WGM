## Datasets

The `data/` directory contains the input datasets, intermediate datasets, and analysis-ready tables required to reproduce the analyses presented in this study.

| Dataset                                   | Path                                                                                                             | Description                                                                                                                                                                                                         | Notes                                                                                                                               |
| ----------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| **Raw DiMSum fitness data**               | `data/raw_fitness_data/` or `data/phix_dimsum_fitness_libraries.rds`                                             | Library-level DiMSum output tables containing raw variant fitness estimates, sequencing statistics, and associated error estimates.                                                                                 | Input to `01_fitness_data_normalization.R`.                                                                                         |
| **Normalized fitness data**               | `data/phix_dms_sub_libraries_normalized.rds`                                                                     | Library-level fitness datasets after within-library normalization and cross-library rescaling.                                                                                                                      | Output of `01_fitness_data_normalization.R`.                                                                                        |
| **All variant fitness dataset**           | `data/phix_all_dms100_sub_libraries_normalized_unique_stat.tsv`                                                  | Combined and deduplicated dataset containing all quantified ΦX174 variants together with statistical analyses and fitness-effect classifications.                                                                   | Primary analysis dataset.                                                                                                           |
| **Single-nucleotide variant dataset**     | `data/phix_all_dms100_sub_libraries_normalized_unique_stat_1nt.tsv`                                              | Analysis-ready dataset of single-nucleotide variants with genomic, functional, and fitness-effect annotations.                                                                                                      | Generated by `03_single_nucleotide_variants.R`.                                                                                     |
| **Complete amino-acid mutation dataset**  | `data/phix_all_dms100_sub_libraries_normalized_unique_stat_AA.tsv`                                               | Complete set of amino-acid-altering variants, including variants with multiple amino acid changes arising from overlapping ORFs.                                                                                    | Source dataset used to construct the analysis-ready single-amino-acid datasets.                                                     |
| **Single-amino-acid variant datasets**    | `data/phix_proteome_dms_mut_Fitness_unique_advanced.tsv`<br>`data/phix_proteome_dms_aa_pos_Fitness_advanced.tsv` | Analysis-ready variant-level and residue-level datasets containing experimentally measured fitness values together with protein, structural, and functional annotations.                                            | Generated by `04_single_amino_acid_variants.R`.                                                                                     |
| **Variant-effect predictor benchmarking** | `data/evaluate_VEPs/`                                                                                            | Benchmarking datasets integrating experimental fitness measurements with computational variant-effect predictor scores, including protein-level and overall performance summaries.                                  | Generated by `05_evaluate_VEPs.R`.                                                                                                  |
| **AlphaFold 3 model evaluation**          | `data/evaluate_AF3_models/`                                                                                      | Intermediate datasets for evaluating protein A–DNA and protein A–C interaction models, including confidence metrics, residue contacts, interface analyses, structural alignments (RMSD), and enrichment statistics. | Large coordinate files and complete AlphaFold 3 prediction outputs are available from Figshare (DOI: 10.6084/m9.figshare.33102308). |



## Supplementary Data

| Dataset                           | Path                           | Description                                                                                                                                                                                                                          |
| --------------------------------- | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Protein annotations**           | `data/proteins_data/`          | Protein secondary structure, relative solvent accessibility (RSA), residue classifications, and protein–protein interaction interface annotations derived from experimentally resolved and predicted structures.                     |
| **Mutant library design**         | `data/mutant_library/`         | Designed and restored mutant libraries, including substitution and synonymous variant identities.                                                                                                                                    |
| **Variant annotations**           | `data/mutant_annotation/`      | Functional and sequence annotations for all designed variants.                                                                                                                                                                       |
| **Structure visualization files** | `data/proteins_data/*.defattr` | ChimeraX attribute files containing residue-level median fitness values for structural visualization.                                                                                                                                |
| **EVcouplings outputs**           | `data/EVcouplings/`            | Multiple sequence alignments, varying-bitscore analyses, and complete EVcouplings output files for all ΦX174 proteins. Original MSA files and associated statistics are available from Figshare (DOI: 10.6084/m9.figshare.33102170). |
